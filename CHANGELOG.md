# Changelog

All notable changes to Disco are documented in this file.

## [1.0.0] - 2026-10-10

### Added
- Initial release: a dark disco theme with animated header, rainbow light bar, glowing menu pills and a mirror-ball logo.
- Support for Redmine 7+ (`themes/` directory).
- Header, login and favicon artwork.
